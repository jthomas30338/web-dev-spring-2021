# Sandbox

Experiments live here, one subfolder per thing being tested. Nothing in
here is production code — treat it as disposable.

- `integrations/` — connecting external services/APIs into a working example (MCP connectors, third-party APIs)
- `workflows/` — multi-agent orchestration experiments (the Workflow tool, pipelines of subagents)
- `automations/` — scheduled/recurring tasks (Routines, triggers, hooks)
- `apis/` — small standalone API call examples/clients

Each experiment should get its own dated or named subfolder with a short
README explaining what it tests and what was learned.
