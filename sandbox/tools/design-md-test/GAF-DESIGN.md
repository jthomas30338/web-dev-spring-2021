# Get AI-Fluent — DESIGN.md (short form)

Paste under any build request: "Build [THING] in this style. One HTML file."

Source: snapshot of the Get AI-Fluent Design System in Claude Design (last updated 8/9/2026).
If the live system has changed, update this file first.

Use only these style rules:
- Fonts: IBM Plex Sans for headlines (600/700), Inter for body (400/500), IBM Plex Mono for numbers in tables. Fallback: system-ui.
- Colours: text #111827, muted text #667085, page #F7F9FC, cards #FFFFFF, sunken #EEF1F6, borders #E5E7EB (subtle) / #D6D6D6 (inputs).
- Brand blue #004AAD (hover #003B87) for the header band, links and key totals. One orange #F76900 (hover #DD5C00) for the primary button, kickers and dividers. Never more than one orange element per view region.
- Status (data only): healthy #1B9E5A, at-risk #F76900, needs attention #D8324B, worst case midnight #050814.
- Corners: 8px on cards, 6px on inputs and buttons. No pills except status badges.
- Shadows: hairline only (0 1px 2px rgba(5,8,20,.06)). No gradients, no glow.
- Spacing: 8pt scale (8, 16, 24, 32, 48, 64).
- Kicker pattern: small uppercase, letter-spaced 0.12em, orange, above the headline. Orange 48px divider under the headline.
- Tagline: "MAKE AI PRACTICAL." small caps, orange, at the foot.
- Motion: fades only, 200ms ease-out. Respect prefers-reduced-motion.
- No stock photos, no raster logo as final, no brand names but ours.
